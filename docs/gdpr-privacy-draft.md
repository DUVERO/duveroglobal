**2. Hvilke oplysninger behandler vi?**
Ved fragtforespørgsler og efterfølgende kundekontakt kan vi behandle firmanavn, registreringsnummer, kontaktpersons navn, e-mail, telefon, virksomheds- og afhentnings-/leveringsadresser, oplysninger om forsendelser, beskeder og eventuelle vedhæftede dokumenter. **3. Formål og behandlingsgrundlag**
Vi bruger oplysninger til at modtage og besvare forespørgsler, udarbejde tilbud, planlægge og administrere transport, kommunikere med kunder og leverandører, dokumentere aftaler og overholde relevante lovkrav. Behandlingsgrundlaget vurderes for hver aktivitet: GDPR artikel 6, stk. 1, litra b (aftale/foranstaltninger før aftale, når relevant for den registrerede), litra f (legitim interesse, fx almindelig B2B-kontakt) og litra c (retlig forpligtelse, hvor relevant). De konkrete legitime interesser og eventuelle andre grundlag skal fastlægges før offentliggørelse.

**4. Modtagere og databehandlere**
Oplysninger kan deles med relevante transportører, agenter og andre samarbejdspartnere, når det er nødvendigt for forespørgslen eller transporten. Den tekniske løsning anvender Cloudflare (bl.a. hosting, Worker, D1, Turnstile og PDF-generering) og Resend (e-mail). Roller, databehandleraftaler, underdatabehandlere og overførselsgrundlag skal verificeres inden offentliggørelse.

**5. Overførsler uden for EU/EØS**
Der kan forekomme internationale dataoverførsler som led i international fragt og anvendelsen af it-leverandører. Lande, overførselsgrundlag og eventuelle supplerende sikkerhedsforanstaltninger skal dokumenteres konkret før offentliggørelse.

**6. Opbevaring og sletning**
Vi opbevarer oplysninger, så længe det er nødvendigt til de relevante formål og eventuelle lovkrav. Konkrete perioder eller kriterier skal fastlægges for ubesvarede forespørgsler, tilbud, kundeforhold, e-mailkorrespondance, kontaktregistre og bogføringsmateriale. Arkivering i Admin er ikke i sig selv sletning. [INDSÆT FASTLAGTE PERIODER].

**7. Oplysninger gemt i browseren**
Hvis brugeren aktivt vælger at få sine kontaktoplysninger husket, kan kontakt- og virksomhedsoplysninger blive gemt lokalt i brugerens browser (localStorage). Dette skal forklares ved valget. Den faktiske cookie- og trackingopsætning skal kontrolleres særskilt.

**8. Dine rettigheder**
Efter GDPR kan du efter omstændighederne have ret til indsigt, berigtigelse, sletning, begrænsning, indsigelse og dataportabilitet. Rettighederne afhænger af behandlingsgrundlaget og den konkrete situation. Kontakt info@duveroglobal.com for en anmodning. Du kan klage til Datatilsynet på www.datatilsynet.dk.

**9. Sikkerhed og ændringer**
Vi anvender tekniske og organisatoriske sikkerhedsforanstaltninger, som løbende skal tilpasses risikoen. Privatlivspolitikken opdateres ved væsentlige ændringer i behandlingen. [INDSÆT DATO FOR GÆLDENDE VERSION EFTER GODKENDELSE].
